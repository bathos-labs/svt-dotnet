# Embedded SVT conformance reference snapshot

This directory contains an explicitly accepted copy of canonical reference data from
[svt-spec](https://github.com/svt-project/svt-spec/tree/6a3ad4f809e33306035e82f1d22c862d385fed03/conformance).
See the
[canonical fixture schema](https://github.com/svt-project/svt-spec/blob/6a3ad4f809e33306035e82f1d22c862d385fed03/conformance/README.md)
and the [snapshot provenance](snapshot.json). The specification source remains authoritative.

The implementation uses these captured bytes offline. Changes upstream do not modify this snapshot.
Read the [adoption and runner guide](../docs/conformance.md) before updating it. Imported reference
files are [MIT-licensed](LICENSE); implementation-specific tests remain outside this snapshot.
